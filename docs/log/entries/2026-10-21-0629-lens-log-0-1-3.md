# lens-log 0.1.3: fixes for M6, M7, M8

## What was done
First tool change from the approved roadmap method (lens-core
`docs/plans/2026-10-21-roadmap-method-proposal.md`, section 4). Test-first:
- **M6:** `entries.py` `_LESSONS` now accepts headings that begin with "Lessons", such as
  `## Lessons learned`.
- **M7:** `state.py` `pending()` skips well-formed JSON lines that are not objects or lack
  `surface`/`evidence`. Before this, one such line raised a KeyError, the Stop hook swallowed
  it, and enforcement was off for the rest of the session.
- **M8:** `entries.py` `coverage()` splits an unbracketed `surfaces: a, b` into names.
- Three new tests; the suite has 77 passing. Version bumped to 0.1.3.

## What was found / decided
These defects silently lost records, and the roadmap's evidence depends on the log. M1, M3,
M4 and M5 are still scheduled along the way.

## Lessons
Generating code edits through a shell heredoc mangles regex escapes. Use the Edit tool for any
line that contains backslashes.
